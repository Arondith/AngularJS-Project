HOW IT WORKS

A simple AngularJS architecture with clear responsibilities.

The project separates persistence, matching logic, and UI state so the code is easy to explain in an interview.

1

Controller

Coordinates forms, filters, metrics, view state, and user actions.

2

Storage factory

Persists demo offers, needs, and impact data in LocalStorage.

3

Matching service

Scores compatible offers and needs with transparent business rules.

4

Filters & directives

Keep repeatable presentation behavior out of the controller.
